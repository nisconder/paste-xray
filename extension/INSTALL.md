# 安装 Paste X-Ray 浏览器插件

1. 解压下载的 `paste-xray-extension-*.zip`。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 打开页面上的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的文件夹。
5. 把 Paste X-Ray 固定到工具栏。

点击工具栏图标可以打开完整检测页。在网页中选中文字并点击右键，可以直接选择“使用 Paste X-Ray 检查选中文字”。

插件只申请右键菜单和临时存储权限，不读取全部网页，也不主动读取剪贴板。

升级时，用新版 ZIP 中的文件替换之前加载的扩展目录内容，然后在浏览器扩展管理页点击该扩展的“重新加载”。当前显示版本为 `1.0.0-beta.2`，内部扩展版本为 `1.0.0.2`。
